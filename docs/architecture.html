Rules a change must never break

  • No score without proof. Minimum scores come only from strictly verified facts; corroboration, press, and self-claims can raise the ceiling but never guarantee points.
  • Safety screens are mandatory. Identity, applicable person or institutional-entity sanctions, institutional legal-entity binding, wallet sanctions, bad-actor graph, and founder-asset checks must all reach their evidence threshold before a report is called complete.
  • Names are never guessed. Person legal and sanctions screens require a provider-verified real person. An institutional organization never borrows that clearance: a strict frozen legal-entity fact must bind the exact entity before its separate OFAC entity screen runs. Generic project accounts show these as follow-ups, not unsatisfiable gates, until their route has equivalent entity collection.
  • Sanctions run fresh every time. Never served from memory, because someone can be sanctioned tomorrow.
  • AI suggestions are leads, not evidence. They never pick the methodology, cap a score, or set a floor.
  • Provider labels stay attributed. A provider or first party can supply useful context, but ARGUS does not silently adopt that description as a verified finding. The facts panel separates source-reported and floor-ineligible supporting context from confirmed facts.
  • Person facts wait for an exact identity bridge. A copied display name, biography, website, or model-discovered employer cannot attach a real person's career, portfolio, legal, or scoring evidence to the audited handle.
  • Portfolio membership is not portfolio quality. Only a canonically bound investor-to-company relationship can enter the graph. Repeated pages support one relationship, and one relationship without outcomes cannot establish a top-tier cohort.
  • Fund size keeps its meaning. AUM, first close, final close, vehicle size, current deployable capital, and personal wealth are separate claims. A bounded empty search proves none of them.
  • Failure is not a clean answer. Empty findings publish only after every required source answered; failed, malformed, capped, and partial reads publish their limits.
  • A person-shaped result is not employment. Web and X candidates, project-account associations, and GitHub contributors stay context until a direct team relationship is grounded.
  • Only immutable graph evidence changes a verdict. Browser submissions and provider risk labels remain research context until a server-collected report version verifies them.
  • Reports are immutable. Once saved they cannot change; every run carries its own cost ledger and cannot save without one.
  • Decision lenses share one truth set. Investment, alpha, counterparty, and general diligence may reorder emphasis, but they never hide a saved risk, revise the score, or buy new data.
  • The parent verdict governs. Direct findings, completeness, score, and verdict stay outside the derived layer. An incomplete parent or an AVOID or FAIL verdict withholds a competing Decision Intelligence thesis.
  • Lineage follows each artifact. Contradicting sources stay beside supporting sources. Token identity, market, liquidity, history, holder-security, and holder-distribution values keep the exact producer that supplied each one.
  • Cross-provider facts rebind before use. TVL and funding need the canonical CoinGecko id; fees need a complete same-slug protocol receipt; holder and control rows need the canonical address and chain. An unbound row stays visible but cannot produce a measurement.
  • Company and chronology labels do not bind themselves. Company enrichment requires an independently resolved non-shared official host, coherent requested and matched hosts, the declared method, matched company website, and valid capture time. It cannot authenticate itself from its own request. RDAP age and launch chronology are recomputed from the exact official hostname, registrable domain, endpoint, and account-creation receipt.
  • Impossible numbers stay receipts. Percentages outside zero to one hundred and circulating supply above total supply are withheld and surfaced as reconciliation gaps.
  • Existing evidence keeps its ceiling. Legal and sanctions name matches are identity-resolution gaps, image classifications are provider opinions, and checked-empty evidence never becomes support. Graph risk needs an exact qualified tie to a complete server-collected adverse report.
  • Missing is never zero. Decision Intelligence keeps absent measurements and failed checks unresolved. It never turns them into clean, safe, unfunded, unaudited, or exonerated claims.
  • One missing axis does not erase the others. The analyst scores every decision area with substantive evidence, preserves unsupported areas as unmeasured, and withholds the overall score until the full role profile is assessed.
  • Cross-source arithmetic is time-bound. Every input needs a valid frozen as-of time within the 72-hour skew policy. A stale or undated comparison is withheld and published as an alignment gap.
  • Lineage fails closed. The final intelligence graph rejects duplicate IDs and dangling source, answer, denominator, signal, arithmetic, temporal, and classification references. Affected questions reopen and the report exposes the integrity gap.
  • Integrity filtering cannot improve an answer. Losing lineage may preserve or weaken unresolved, unavailable, or not-collected states, never upgrade them. Evidence-bearing signals must retain their complete measurement and source graph.
  • Provider omission stays unanswered. Incident recovery has three states: yes, no, and not recorded. A missing field cannot become No or an unrecovered-loss claim.
  • Unrequested sections are not empty sections. Missing company funding or management enrichment renders not collected, never zero rounds or no managers.
  • Saved chronology cannot drift. Leadership age and every persisted point-in-time label use a frozen report or source timestamp, never the viewer's clock.
  • EVM evidence is chain-bound. The public RPC must return the expected chain ID before any block or contract read. No bytecode never means one key, and a Safe-compatible interface never authenticates an official Safe.
  • An audit name is only a lead. Corroboration requires an auditor-owned page with explicit audit context, the subject name, and a canonical domain or contract anchor in the same saved proof window.
  • Challenge evidence comes from storage. The browser sends the analyst's question only; the server reloads the exact authenticated report before asking for a second opinion.
  • Time is budgeted. Evidence gathering stops early enough that scoring and the bad-actor screen always get their full window.
  • One build path. Server code ships inside one bundle; deploys happen only by pushing main.

Jargon, translated

  • API A door that other software (not people) uses to ask a system for something and get a structured answer back.
  • v1 Version 1 of a public interface. Numbering it lets it evolve later (v2) without breaking anyone already plugged in.
  • Route / endpoint One specific door with one job, like "start an investigation" or "open a saved report."
  • Serverless Code that only exists while handling a request, then vanishes. No servers to babysit; each run pays only for itself.
  • SSE / stream A connection held open so the server can keep sending updates live, which is how you watch evidence arrive in real time.
  • Adapter / collector A specialist module that knows how to fetch one kind of evidence, so the engine can send many out at once.
  • Provider An outside company or dataset we pay (or use free) for raw data: Google results, court records, chain data.
  • Immutable Cannot be changed after saving. Re-running creates a new version instead of editing history.
  • Cache A short-term copy of an answer so asking the same question twice does not cost twice.
  • Quota A daily spending allowance per member, enforced before any paid work starts.
